## Shop editor

`/admin` is where products are added, removed, priced and stocked. It's
password-protected (`ADMIN_PASSWORD` in `.env.local`). Changes are live on the
next page visit. `src/lib/commerce/catalogue.ts` is the starting list; the
editor's changes sit on top of it (`src/lib/commerce/inventory.ts`) in the
store (`src/lib/store.ts`: `.data/` here, Netlify Blobs online).
Going online: [DEPLOY.md](DEPLOY.md). End-to-end check:
`node scripts/perf/admin.cjs http://localhost:3093 <out dir>`.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
